# 一键导卡

**面向摄影、摄像与后期制作工作流的素材导入与处理工具。**

一键导卡最初用于解决拍摄后存储卡素材整理、复制和归档的问题。经过持续开发，目前已经形成一套集 **设备识别、素材导入、校验备份、任务管理、转码、素材浏览、现场自动导入和局域网协作** 于一体的工作流工具。

---

## 核心功能

### 导卡

面向相机卡与录音卡设计的素材导入流程。

* 自动识别厂商、型号、序列号和机位
* 支持视频、照片、RAW、音频及伴随文件
* 支持视频 + 照片 / 仅视频 / 仅照片等导入模式
* 支持增量导入、重复素材检测
* 支持断点续传
* 支持恢复未完成任务
* 支持多目标导出与备份
* 支持混卡识别与按机型分类归档
* 支持项目名称、机位号、卡号等归档信息

### 素材安全

导卡过程尽可能围绕“**素材可确认、源文件不误删**”进行设计。

* 导入前检查目标磁盘空间
* 文件导入校验
* 重复素材检测
* 断点续传
* 删除前预检
* 安全删除
* 目标文件异常时自动保留源素材
* 导入失败提供详细原因
* 导入完成后生成导出记录

重复检测采用文件名、大小和快速哈希等信息；执行安全删除时可使用更严格的内容校验。

### 相机识别

通过多种素材证据综合判断设备型号，包括：

* 相机目录结构
* 视频 / 剪辑元数据
* EXIF / XMP
* 厂商与型号指纹
* 素材拍摄时间
* 相机序列号

针对未重新格式化、先后使用不同相机的存储卡，也支持混卡识别与机型仲裁，并按照识别结果进行素材归档。

未知设备不会强行套用错误型号，无法确认时会尽可能保留原始信息。

## 任务队列

导卡和转码任务统一进入任务队列。

支持：

* 多任务并行
* 并发数量控制
* 排队调度
* 失败重试
* 断点恢复
* 程序重启后恢复任务
* 任务完成摘要
* Windows 系统通知
* 局域网任务状态查看

---

## 转码

基于随包 FFmpeg / ffprobe 构建。

支持：

* H.264 / H.265 / VP9 / AV1 等编码
* 硬件编码加速
* 分辨率 / 帧率调整
* 跟随原素材
* CRF / CQ 质量模式
* 两遍编码
* HDR → SDR
* 色彩空间转换
* 音频响度标准化
* LUT 还原
* 自定义 FFmpeg 参数
* 批量转码
* 自定义预设
* 文件级断点续传

同时提供代理工作流：

* 自动生成 Proxy 文件夹
* 代理文件与原素材关联
* 自动生成 CSV / EDL / XML 清单

便于在 Premiere Pro、DaVinci Resolve 等后期软件中继续使用。

---

## 素材浏览器

插入存储卡后，可以直接浏览卡内素材。

支持：

* 视频 / 照片 / 音频筛选
* 文件名、路径、日期、相机、类型、扩展名搜索
* 文件名、拍摄时间、大小、时长、类型排序
* 缩略图浏览
* 多选以及批量转码
* 源文件删除
* 媒体详细信息
* 卡内文件刷新

素材详情会根据媒体类型显示不同信息。

视频可以查看时长、分辨率、帧率、码率、编码、色彩、位深等信息；

照片支持 EXIF / TIFF 信息，包括 RAW 素材；

音频支持时长、码率、编码、采样率、位深等信息。

---

## 快捷预览

素材浏览器提供面向现场筛片的快捷浏览方式：

**鼠标移动到素材卡片 → 按住空格**

即可快速预览。

支持：

* 视频播放
* 视频进度定位
* 音频播放
* 图片缩放
* 图片拖动
* RAW 素材浏览

视频预览使用随包 FFmpeg 解码，以提高对专业视频格式的兼容性。

---

## 局域网任务

同一局域网内的多台电脑可以互相查看任务状态。

可以共享：

* 正在进行的任务详情
* 项目名称

远程任务以只读形式显示，不会直接控制其它电脑上的任务，也不会直接访问对端磁盘。

同时提供局域网广播、详情查看和项目名称同步等独立控制项。

## 工具箱

工具箱采用模块化设计。

工具以独立模块加载，可以在不影响主程序核心功能的情况下增加或移除工具。

当前提供：

### 在线导入

用于拍摄现场自动导卡。

### 快捷格式转换

用于快速转换图片、音频和视频格式。

支持根据媒体类型提供对应的目标格式，并提供批量处理、抽帧、提取音频等功能。

## 日志与归档

软件会记录主要业务操作，包括：

* 导入
* 导入历史
* 转码
* 删除
* 删除已转码原素材
* 导入失败
* 相关操作结果

日志支持：

* 搜索
* 筛选
* 分页
* 详情查看
* 自定义日志目录
* 网络共享日志目录

每次导卡完成后，还会在项目目录中维护：

```text
[日期][项目名]_导出详情.xlsx
```

用于记录项目、日期、导出时间、相机、机位、卡号、素材数量、总容量、目标位置、文件状态等信息。

## 工作流

一键导卡希望覆盖的不只是“复制文件”这一步，而是完整的素材前期处理流程：

```text
存储卡
  ↓
设备识别
  ↓
素材扫描
  ↓
导入归档
  ↓
校验 / 备份
  ↓
转码 / 代理
  ↓
素材浏览
  ↓
任务管理
  ↓
日志与导出记录
```

核心目标是减少重复操作，并尽可能降低拍摄现场和素材归档过程中的人为错误。

* 后台素材扫描
* 后台元数据读取
* 任务状态持久化
* 原子写盘与备份恢复
* 导入断点续传
* 转码断点续传
* 异常退出后的任务恢复
* 技术日志与业务日志分离

在实际测试中，大量素材同时存在时仍保持界面可交互。
